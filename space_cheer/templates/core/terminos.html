{# ── 2. Descripción del servicio ────────────────────────────────────── #}

2. {% trans "Descripción del Servicio" %}

{% blocktrans %} SPACE CHEER es una plataforma digital orientada a la gestión integral de equipos de porrismo (cheerleading). Los servicios disponibles incluyen: {% endblocktrans %}

  • {% trans "Gestión de equipos: membresías, roles de atleta, coach y staff." %}
  • {% trans "Pedidos de uniformes personalizados y productos relacionados." %}
  • {% trans "Registro y administración de medidas corporales de atletas." %}
  • {% trans "Calendario y seguimiento de competencias y eventos de cheerleading." %}
  • {% trans "Comunicación interna entre miembros del equipo." %}
  • {% trans "Acceso a contenido social del equipo (feed, publicaciones, galería)." %}

{% blocktrans %} El acceso a las distintas funciones depende del rol asignado al usuario (ADMIN, HEADCOACH, COACH, STAFF, ATLETA, ACOMPAÑANTE) y de la suscripción activa del equipo. {% endblocktrans %}

{# ── 4. Pedidos de uniformes ────────────────────────────────────────── #}

4. {% trans "Pedidos de Uniformes: Proceso, Pagos y Cancelaciones" %}

{% trans "Proceso de pedido" %}

{% blocktrans %} Los pedidos de uniformes siguen un flujo definido de estados: BORRADOR → PENDIENTE → DISEÑO APROBADO → EN PRODUCCIÓN → ENTREGADO. El pedido puede cancelarse antes de que entre en producción. {% endblocktrans %}

  • {% trans "Las medidas de los atletas deben registrarse dentro del plazo indicado por el HEADCOACH." %}
  • {% trans "Una vez aprobado el diseño, las medidas quedan bloqueadas y no pueden modificarse." %}
  • {% trans "El usuario recibirá notificaciones por correo electrónico en cada cambio de estado." %}

{% trans "Pagos" %}

{% blocktrans %} Los precios de los uniformes y productos se muestran en pesos mexicanos (MXN) e incluyen IVA cuando aplique. Los métodos de pago disponibles y las condiciones de pago se especificarán en cada pedido. SPACE CHEER no almacena datos de tarjetas de crédito o débito. {% endblocktrans %}

{% trans "Cancelaciones" %}

{% blocktrans %} Las cancelaciones solo se aceptan antes de que el pedido entre en estado EN PRODUCCIÓN. Una vez iniciada la producción, no se aceptarán cancelaciones ni reembolsos, salvo defecto de fabricación comprobable. {% endblocktrans %}

{% trans "Garantías" %}

{% blocktrans %} SPACE CHEER garantiza que los productos entregados corresponderán a las especificaciones del pedido aprobado. En caso de defecto de fabricación, el usuario deberá notificarlo dentro de los 7 días naturales posteriores a la recepción del pedido, adjuntando evidencia fotográfica. SPACE CHEER evaluará cada caso y determinará la solución apropiada (reposición, reparación o crédito). {% endblocktrans %}

{# ── 5. Protección de datos de menores ─────────────────────────────── #}

5. {% trans "Protección de Datos de Menores de Edad" %}

{% blocktrans %} SPACE CHEER maneja datos de menores de edad de conformidad con la Ley General de los Derechos de Niñas, Niños y Adolescentes (LGDNNA) y la Ley Federal de Protección de Datos Personales en Posesión de los Particulares (LFPDPPP). {% endblocktrans %}

{% blocktrans %} El registro y tratamiento de datos personales de atletas menores de 18 años requiere el consentimiento expreso del padre, madre o tutor legal (en adelante "el Tutor"). Al registrar a un menor en la Plataforma, el Tutor declara: {% endblocktrans %}

  • {% trans "Ser el padre, madre o tutor legal del menor." %}
  • {% trans "Autorizar el tratamiento de los datos personales del menor, incluyendo nombre, fecha de nacimiento, CURP y medidas corporales, para los fines de la Plataforma." %}
  • {% trans "Que la información proporcionada es veraz y está actualizada." %}
  • {% trans "Comprender que puede revocar este consentimiento en cualquier momento, solicitándolo a space.cheer.space@gmail.com." %}

{% blocktrans %} Los datos de menores están sujetos a controles adicionales de acceso dentro de la Plataforma. Solo el personal autorizado del equipo (HEADCOACH, COACH, STAFF) y el propio Tutor vinculado podrán consultar esta información. {% endblocktrans %}

{% blocktrans %} SPACE CHEER no compartirá datos de menores con terceros, salvo obligación legal expresa. Los Tutores pueden ejercer los derechos ARCO (Acceso, Rectificación, Cancelación y Oposición) enviando una solicitud a space.cheer.space@gmail.com. {% endblocktrans %}
