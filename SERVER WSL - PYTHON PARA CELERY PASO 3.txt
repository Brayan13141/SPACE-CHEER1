============================================== GNU GETTEXT (i18n) =================================
HERRAMIENTA DE SISTEMA — instalar GLOBAL en Windows (no va en el virtualenv)
Django la necesita para: makemessages (extrae strings) y compilemessages (genera .mo)

WINDOWS (ejecutar como Administrador):
    Opción A — winget:
        winget install GnuWin32.GetText

    Opción B — instalador completo (recomendado, más estable):
        https://mlocati.github.io/articles/gettext-iconv-windows.html
        Descargar "gettext X.X.X iconv X.X.X - shared - x86-64"

Agregar al PATH de Windows si no se agrega automáticamente:
    C:\Program Files\gettext-iconv\bin   (mlocati)
    C:\Program Files (x86)\GnuWin32\bin  (GnuWin32)

Verificar instalación (cmd o PowerShell):
    msgfmt --version

EN WSL/LINUX es más simple:
    sudo apt install gettext

Comandos de uso (desde space_cheer/ con venv activo):
    python manage.py makemessages -l es -l en   # extrae strings de templates y código
    # editar locale/en/LC_MESSAGES/django.po con traducciones al inglés
    python manage.py compilemessages             # compila .po → .mo (binario que Django lee)
